# Ather3D Setup & Run Documentation

This folder contains documentation and structural references for Ather3D.

For complete project documentation, see the root [README.md](../README.md).

---

## Quick Run Reference

```bash
# 1. Install dependencies
npm install

# 2. Start MongoDB service
# Windows:
net start MongoDB
# Linux/macOS:
sudo systemctl start mongod

# 3. Start Application Server
npm run dev   # Or: npm start

# 4. Open in Browser
# http://localhost:5000
```

For full details on configuration, environment variables, user roles, and troubleshooting, refer to [../README.md](../README.md) and [file_structure](./file_structure).
